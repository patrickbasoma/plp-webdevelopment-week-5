
# SpendWise - Personal Budget and Expense Tracker

## Project Description

SpendWise is a personal budget and expense tracking
application developed using HTML, CSS, and JavaScript.

The application helps users understand their budget,
track expenses, and calculate their remaining balance.

## Technologies Used

- HTML - Creates the webpage structure.
- CSS - Styles the application.
- JavaScript - Processes user input and performs
  budget calculations.

## JavaScript Concepts Implemented

### 1. Variables
Used let to store the total budget, expenses,
and remaining balance.

### 2. Data Types
Used numbers to represent financial amounts.

### 3. User Input
Used prompt() to collect budget and expense
information from users.

### 4. Calculations
Used subtraction to calculate the remaining balance.

### 5. Functions
Created calculateBalance() to calculate the
remaining budget.

Created displaySummary() to display the results.

### 6. Conditional Statements
Used if, else if, and else to validate input
and determine the budget status.

### 7. Console Output
Used console.log() to display the budget summary
in the browser console.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in Google Chrome.
4. Enter your budget and expenses when prompted.
5. Open Developer Tools and select Console
   to view the results.

## Project Goal

The goal of SpendWise is to demonstrate the
fundamentals of JavaScript through a practical
personal budgeting application.
